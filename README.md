# 📸 Photo Battle Bot

Telegram-бот для фотобатлов в формате **турнира на выбывание**:

1. Админ назначает батл, например на 14:00.
2. До старта участники присылают в бота **фото или видео**. Бот только собирает их и ничего не публикует.
3. В 14:00 бот случайно разбивает работы на **пары** и присылает **админу в личку готовые посты**: два фото склеены в одну картинку с метками «1» и «2», подпись — по оформлению админа, включая премиум-эмодзи.
4. Админ пересылает каждый пост в канал **без автора** (можно поправить подпись). Бот узнаёт свой пост в канале и **сам отвечает под ним кнопками** «Підтримати 1 · N», «Підтримати 2 · M» и «⭐ +1 голос» — голосование началось.
5. Голосуют **подписчики канала**. Работа с большим числом голосов проходит в следующий раунд — и так до финала.
6. **Ничья:** бот готовит пост пары заново на 10-минутное переголосование, голоса считаются с нуля.
7. Авторы **нигде не указываются**. Победитель объявляется в канале без имени и получает поздравление в личку.

Бот сам ничего не публикует в канале, кроме сообщений с кнопками голосования: анонсы, посты пар и пост победителя приходят админу готовыми к пересылке. Поэтому оформление может быть **любым, с премиум-эмодзи**. Дополнительные голоса продаются за **Telegram Stars** и **картой**. Интерфейс на украинском и русском языках.

**Стек:** Node.js 22 · TypeScript · Telegraf 4.16 · PostgreSQL 16 + Prisma 7 · Redis + BullMQ 6 · sharp · zod · pino · Vitest · Docker.

## Как выглядит для участника

**Меню:** 📸 Надіслати фото або відео · ⭐ Купити голоси · ⚔️ Поточний батл · ℹ️ Правила · ❓ Допомога.

Другие разделы доступны командами: `/myphotos` (мои работы и удаление), `/stats` (моя статистика), `/language` (язык), `/deletedata` (удалить всё), `/paysupport` и `/terms` (оплата).

**Отправка работы:**
1. Нажать «📸 Надіслати…». Если батл не запланирован, бот ответит, что приём закрыт.
2. При первой отправке — дать согласие на публикацию (без указания имени).
3. Отправить фото (как фото или файл JPG/PNG/WEBP) или видео (до `MAX_VIDEO_DURATION_SECONDS`).
4. Бот проверяет файл. Фото скачивается и полностью декодируется (формат, размер, разрешение, целостность), у файлов удаляются EXIF и GPS. Повторно отправить ту же работу нельзя.
5. Предпросмотр → «✅ Підтвердити». Работа ждёт старта, бот сообщает время.
6. Когда пара выходит в канал, бот присылает ссылку. После каждого раунда приходит результат.

**Голосование под постом:** «Підтримати 1/2» — один бесплатный голос в паре; повторное нажатие отменяет голос, нажатие на другую работу переносит его. Голосовать могут только подписчики канала (настраивается), за свою работу — нельзя.

`/admin` или кнопка «🛠 Адмін-панель». Доступ — только Telegram ID из `ADMIN_IDS`; права проверяются на сервере, попытки доступа без прав записываются в журнал.

Видно ход: раунд, сколько пар завершено и ждут публикации. Если пара не опубликована 10 минут, бот напомнит. Отмена. |

## Как устроен турнир

```
SCHEDULED ──(время старта)──► RUNNING: раунд 1 ─► раунд 2 ─► … ─► FINISHED (победитель)
  приём работ                  пары → голосование → победители дальше
```

- **Старт.** В назначенное время (с точностью до секунды — для старта ставится отложенный тик) все принятые работы перемешиваются (`crypto.randomInt`) и разбиваются на пары. При нечётном числе работ в любом раунде без голосования дальше проходит работа, присланная последней (по времени подтверждения). Работы, не прошедшие модерацию к старту, в батл не попадают. Если работ нет — батл не состоялся; если одна — она побеждает.
- **Подготовка постов.** Посты пар приходят каждому админу по очереди (пауза `DUEL_POST_INTERVAL_SECONDS`). Перед каждым — подсказка «Раунд 1 · Пара 3 — перешли пост ниже в канал без автора». Два фото → одна склеенная картинка; если в паре есть видео → альбом с подписью. Временные ошибки Telegram повторяются.
- **Публикация админом.** Перешлите пост в канал без автора: Переслать → Скрыть отправителя (в Telegram Desktop — «Переслать без автора»). Подпись можно изменить. Бот получает новый пост канала, узнаёт его по файлу (у пересланной копии тот же `file_unique_id`), отвечает под ним сообщением с кнопками и пишет админу «Пара опубликована, голосование до …». Если файл заменить (скачать и загрузить заново), бот пост не узнает.
- **Голосование** длится `roundMinutes` с момента публикации пары админом. Пока админ не опубликует все пары раунда, следующий раунд не начнётся; прогресс видно в «⚔️ Батли». Счётчики на кнопках обновляются не чаще раза в 2 секунды.
- **Итог пары.** Больше голосов — проходит. Ничья — бот готовит новый пост на переголосование (`TIEBREAK_MINUTES`, голоса с нуля), до `MAX_TIEBREAKS` раз. Если ничья сохраняется, проходит работа, отправленная раньше. Кнопки старого поста закрываются, у победителя появляется 🏆.
- **Следующий раунд** создаётся автоматически, как только завершены все пары текущего: админ получает анонс раунда и посты новых пар. Финал — готовый пост с работой-победителем без имени автора.
- **Надёжность.** Состояние хранится в PostgreSQL. Каждый переход защищён условием на ожидаемый статус, поэтому повторные и параллельные тики безопасны. Каждый этап пары публикуется ровно один раз, а после перезапуска бот продолжает с того же места.

## Оформление постов и премиум-эмодзи

Админ-панель → «🎨 Оформлення» → выберите пост → «✏️ Завантажити своє» → отправьте боту **одно сообщение**, оформленное как будущий пост: жирный, курсив, ссылки, цитаты, **премиум-эмодзи**. Бот сохранит оформление и покажет предпросмотр.

| Пост | Подстановки |
|---|---|
| ⚔️ Пост пары | `{battle}`, `{stage}`, `{roundName}`, `{round}`, `{duel}` |
| 📢 Анонс батла | `{battle}`, `{start}` (время старта), `{bot}` (@бот) |
| 🔁 Анонс раунда | `{battle}`, `{roundName}`, `{round}`, `{entries}` |
| 🏆 Пост победителя | `{battle}`, `{votes}` |
| 🗳 Подпись над кнопками | `{stage}`, `{roundName}`, `{round}`, `{duel}` |

- `{roundName}` — «Раунд 1», «Полуфинал» (3–4 работы) или «Финал» (последняя пара).
- `{stage}` — «Раунд 1 · Пара 3», «Полуфинал · Пара 2», «Финал»; при ничьей с «⚡ Переголосование!».
**Финал на 3–4 работы.** При создании батла (последний шаг) или кнопкой «🏁 Фінал: N роботи» на экране «Батли» выбирается, сколько работ будет в финале: 2 (обычная пара), 3 или 4. Когда оставшиеся работы помещаются в финал, все они выходят **одним постом** (коллаж 3 в ряд или 2×2, для видео — альбом) с кнопками «Підтримати 1 / 2 / 3 / 4». Побеждает работа с наибольшим числом голосов; ничья за первое место — переголосование. Оформление — отдельно «Фінал (3 роботи)» и «Фінал (4 роботи)» (если не загружено, берётся «Фінал»). Пример: 12 работ и финал на 3 → 6 пар → 3 пары → финал из 3 работ. Размер можно менять, пока финал не начался.

**Места в финале за звёзды.** Во время батла можно купить место сразу в финале — за `FINAL_SPOT_PRICE` ⭐ (по умолчанию 25), не больше `FINAL_SPOTS` мест на батл (по умолчанию 2, `0` — выключить). Кнопка «🎟 Купити місце у фіналі» появляется в «⚔️ Поточний батл» (и команда `/final`) только когда продажа открыта:
- со 2-го раунда (если в батле больше 24 работ — с 3-го) и до начала финала;
- купить может любой, даже без работы в батле, кроме тех, чья работа ещё в игре; одно место на человека;
- финал вмещает максимум 4 работы, поэтому мест продаётся не больше, чем `4 − размер финала`.

После оплаты бот просит прислать фото или видео (можно свою же прежнюю работу; чужую — нельзя), до начала финала его можно заменить. Когда начинается финал, купленные места попадают в пост финала вместе с обычными финалистами. Если фото не прислали до финала или батл отменили — звёзды возвращаются автоматически; если последнее место купили на секунду раньше — тоже. Кто купил место, видят только админы.

**Конец раунда.** Админ-панель → Батли → «⏰ Змінити кінець раунду»: введите время (`16:00` или `09.11 16:00`) — все пары текущего раунда, и уже опубликованные, и пересланные позже, закончатся в это время; затем начнётся следующий раунд с обычной длительностью.

- `{end}` — до скольки идёт голосование («16:00»). В подписи над кнопками — точное время; в посте пары и анонсе раунда — расчётное (от момента подготовки поста).

**Отдельно по раундам.** У поста пары, анонса раунда и подписи над кнопками прямо на экране шаблона есть кнопки «Раунд 1», «Раунд 2», «Раунд 3», «Раунд 4», «Фінал» — для каждого можно загрузить своё оформление (например, «ФИНАЛ» буквами из премиум-эмодзи). Порядок выбора: финал (последняя пара) → номер раунда → общее оформление → стандартный текст.

> Все посты, кроме подписи над кнопками, приходят админу в личку, а он пересылает их в канал. Премиум-эмодзи в сообщениях бота работают, если **у владельца бота есть Telegram Premium** (Bot API 9.4); при пересылке они сохраняются. Подпись над кнопками публикует сам бот, поэтому премиум-эмодзи в ней заменяются обычными: для этого нужен username бота, купленный на Fragment.
>
> Если подготовленный пост переслали в другой канал, бот сообщит об этом админу.

## Платные голоса (Звёзды и карта)

- Кнопка «⭐ +1 голос» под парой открывает бота → «За яку роботу?» → пакеты (Звёзды или карта) или «🎁 +N з балансу».
- Купленные голоса **сразу добавляются выбранной работе в текущей паре** (на текущем этапе голосования). Если пара успела завершиться до оплаты, голоса зачисляются на баланс.
- Меню «⭐ Купити голоси» продаёт голоса на баланс; потратить их можно через «⭐ +1» под любой активной парой.
- Каждая оплата зачисляется ровно один раз (по `telegram_payment_charge_id`). Перед оплатой (pre-checkout) бот проверяет сумму, покупателя и то, что пара ещё открыта.
- **Включение:** Адмін-панель → 💰 Платежі → «Увімкнути продаж голосів» (по умолчанию выключено). Цены по умолчанию: 5 / 20 / 50 голосов — 25 / 90 / 200 ⭐ и 25 / 89 / 199 ₴. Цены меняются там же.
- **Звёзды** работают без настроек. Выводятся через @BotFather → бот → Payments (Fragment).
- **Карта:** @BotFather → бот → **Payments** → провайдер → токен в `PAYMENT_PROVIDER_TOKEN`, после чего в меню появятся кнопки «💳».

> ⚠️ Голоса — цифровой товар. По правилам Telegram цифровые товары внутри ботов продаются **только за Звёзды**. Приём оплаты картой через провайдера может привести к ограничениям для бота — это решение владельца.

### Оплата переводом на карту или в банку Monobank (без ФОП)

Если провайдер Telegram не подключён, кнопка «💳» ведёт на перевод:
1. Покупатель выбирает пакет → бот показывает **реквизиты**, **сумму** и **код** (например, `PB7K2Q9`), который нужно указать в комментарии к переводу.
2. Покупатель переводит деньги и нажимает **«✅ Я оплатив»**.
3. **С Monobank** бот раз в минуту читает выписку выбранной банки или карты, находит перевод по коду и точной сумме и **сам начисляет голоса**. Регистр, пробелы и дефисы в коде не важны. Одна банковская операция не может оплатить два заказа.
4. **Без Monobank** или если перевод не нашёлся за `TRANSFER_TTL_MINUTES`, админам приходит заявка с кнопками ✅/❌. Неподтверждённая заявка отменяется через `TRANSFER_REVIEW_HOURS`, покупателю приходит уведомление.
5. Неоплаченный заказ отменяется через `TRANSFER_TTL_MINUTES`.

Настройка: 💰 Платежі → «💳 Увімкнути переказ на картку» → «✏️ Реквізити» (номер карты или ссылка на банку). Для автопроверки:
1. Получите личный токен на **api.monobank.ua** (QR-код в приложении). Токен даёт **только просмотр** выписки.
2. Добавьте его в Railway как `MONOBANK_TOKEN` и сделайте Deploy.
3. В «🏦 Рахунок Monobank» выберите банку или карту. Если реквизиты ещё не заданы, ссылка банки подставится сама.

Заявки на перевод можно посмотреть в «🔎 Заявки на переказ».

Возврат Звёзд: 💰 Платежі → 🧾 Останні оплати → «↩️ Повернути». Голоса, ещё не учтённые в завершённых парах, списываются. Оплату картой возвращают в кабинете провайдера.

## Настройка: бот, канал, переменные

**1. Бот.** @BotFather → `/newbot` → получите токен (`BOT_TOKEN`). Никому его не показывайте; если токен утёк — `/revoke`.

**2. Канал.** Создайте канал и добавьте бота **администратором** с правами «Публікація повідомлень» (кнопки голосования), «Редагування чужих повідомлень» и «Видалення чужих повідомлень» (удаление поста, если работа выбыла). Бот должен быть админом, чтобы видеть новые посты канала. `ADMIN_IDS` обязателен: посты приходят этим людям.

**3. ID канала.** Публичный канал → `CHANNEL_ID=@имя_канала`. Частный → перешлите пост из канала боту @getidsbot или @userinfobot и возьмите число `-100…`.

**4. Свой Telegram ID** (для `ADMIN_IDS`) — у @userinfobot, только цифры.

**5. Переменные** (`cp .env.example .env`):

| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `BOT_TOKEN` | ✅ | — | Токен от BotFather |
| `CHANNEL_ID` | ✅ | — | `@username` или `-100…` |
| `ADMIN_IDS` | ✅* | — | Telegram ID админов через запятую (*без них админки нет) |
| `DATABASE_URL` | ✅ | — | PostgreSQL |
| `REDIS_URL` | ✅ | `redis://localhost:6379` | Redis |
| `DEFAULT_LANGUAGE` | | `uk` | `uk`/`ru`: язык постов в канале и пользователей с другим языком Telegram |
| `TIMEZONE` | | `Europe/Kyiv` | Часовой пояс времени старта и дат |
| `MAX_VIDEO_DURATION_SECONDS` | | `180` | Максимальная длина видео |
| `MAX_PHOTO_SIZE_MB` | | `10` | Размер фото (≤ 20 — лимит Bot API) |
| `MIN_PHOTO_DIMENSION` / `MAX_PHOTO_DIMENSION` | | `320` / `10000` | Разрешение фото |
| `DUEL_POST_INTERVAL_SECONDS` | | `5` | Пауза между постами пар |
| `TIEBREAK_MINUTES` | | `10` | Длительность переголосования при ничьей |

## Проверка работоспособности
1. Логи: `Authorized in Telegram` → `Channel resolved` → `Background workers started` → `Long polling started`.
2. `curl http://localhost:8080/health` → `{"status":"ok","database":true,"redis":true}`.
3. `/admin` → ⚔️ Батли → запланировать батл через 2–3 минуты. В канале появится анонс.
4. С двух аккаунтов отправить по фото и подтвердить. До старта в канале ничего нет.
5. Во время старта вам придут подсказка и готовый пост пары. Перешлите его в канал без автора — под ним появятся кнопки, авторы получат ссылку.
6. Проголосовать с аккаунта-подписчика — счётчик на кнопке обновится.
7. По окончании голосования кнопки закроются, у победителя появится 🏆; при двух работах сразу выйдет пост победителя.

## Ограничения
- **Ручная публикация:** голосование в паре начинается, когда админ перешлёт её пост; следующий раунд ждёт, пока опубликованы все пары. Кнопки — отдельным сообщением под постом (на пост админа бот не может поставить кнопки). Премиум-эмодзи требуют Telegram Premium у владельца бота.
- **Видео** не склеиваются: пара с видео выходит альбомом, кнопки — отдельным сообщением под ним.
- **Фото** до 20 МБ — лимит скачивания Bot API (для склейки бот скачивает фото). Видео не скачиваются, их размер не ограничен ботом.
- **Polling** допускает один экземпляр бота; для масштабирования используйте webhook.
- **Точность времени:** старт и конец каждой пары обрабатываются в назначенный момент; страховочный тик — раз в 30 секунд.
- **Оплата картой** цифровых товаров противоречит правилам Telegram — см. раздел о платных голосах.
